Sobre o Projeto

O SyncPulse é uma interface profissional e motor de automação desenvolvido para simplificar a gestão de storage híbrida no ZimaOS. Este software atua como uma ponte inteligente entre o seu hardware e os principais serviços de Cloud do mercado.

Open Source & Credits

O SyncPulse utiliza o motor Rclone (rclone.org) como backend de comunicação. O Rclone é um software de código aberto distribuído sob a Licença MIT. Nós orgulhamo-nos de apoiar e utilizar tecnologias open-source para garantir a robustez do nosso serviço.

Privacidade de Dados

A sua segurança é a nossa prioridade. Todas as credenciais de Cloud e chaves de acesso são encriptadas e guardadas localmente no seu ZimaOS. O SyncPulse não tem acesso aos seus ficheiros nem envia dados privados para servidores externos.

Remote storage management

Prefer the terminal?
1

Run the configurator in your ZimaOS terminal:

sudo docker exec -it SyncPulse rclone --config /config/rclone.conf config
2

In the menu, choose “n” (New Remote), give it a name, and select the provider.

3

Answer the critical questions as follows:

Edit advanced config? n
Use web browser auth? n

Rclone will generate a link. Open it, authorize, and paste the code back into the terminal.

Preferências

Ativação da licença

A licença desbloqueia sincronização e automatismos.

Inativa

Sem licença, pode simular, mas não iniciar/parar sincronizações nem usar processos automáticos.

Simulação Prévia

Executar simulação antes de sincronizar.

Nota: Desativar a simulação prévia torna o início da sincronização instantâneo, mas remove a previsão de alterações na fila.
